FORMULA ANZIANI - regole Firebase da AGGIUNGERE (a mano, da Alberto)
Console Firebase > progetto "super-capone" > Realtime Database > Regole.
Dentro  "arcade": { ... }  accanto a "supercapone" aggiungi il blocco "formulaanziani":

"formulaanziani": {
  "plays": { ".read": false, "$id": { ".write": "!data.exists()", ".validate": "newData.hasChildren(['n','s'])" } },
  "stats": { ".read": true, ".write": true },
  "top":   { ".read": true, "$k": { ".write": true } }
}

Se non le aggiungi il gioco funziona lo stesso, ma classifiche, partite e statistiche non vengono salvate.
